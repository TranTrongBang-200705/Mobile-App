# PCAT implementation log (2026-10-24 to 2026-10-25)

This log separates the EdNet offline experiment from the live placement demo.

## Changes made

- `scripts/run_code/run_full_balanced_lr.py`: added a separate, resumable five-seed 100-generation/80-population NSGA-II runner using `--content-balance listening_reading`. It uses separate `_balancedLR` results, checkpoints, logs, and status so the completed historical run is preserved. After a memory allocation failure with two parallel seeds, the runner was changed to one seed at a time and to fail immediately on a seed error.
- `scripts/run_code/run_full_balanced_lr.py` and `watch_balanced_parallel.ps1`: added an opt-in switch to two seed workers only after VS Code has closed and Windows reports at least 1.5 GB free physical memory plus 3 GB commit headroom. The new runner also checks available memory before starting a second worker. The watcher stops the existing sequential runner only after those checks, retains per-generation optimizer checkpoints, resumes unfinished seeds, and falls back to one worker if parallel execution fails from memory exhaustion. It does not affect the paused BOBCAT experiment.
- `scripts/run_code/aggregate_seed_results.py`: added `--suffix _balancedLR` and a balance-method check when combining the five new results.
- `pcat_server.py`: created a session for each 20-question path, removed answer keys and explanations from the question responses, checked exact question IDs/answer indices at both submissions, and rejected a Stage 2 paper that differs from the branch assigned by the server. Routing uses an NCD mastery threshold calculated on the training cohort instead of the previous raw-score overrides and fixed 0.48 heuristic. Diagnosis returns NCD mastery indices with item counts; the unsupported 20-to-990 TOEIC score conversion and automatic CEFR/roadmap mapping were removed from this API. The server validates stage sizes, Listening/Reading balance, full bundles, answer keys, content, audio, and Part 1 images at startup.
- `pcat_server.py`: replaced the two live Part 1 demo items (q2 and q0), which had no photos, with available Part 2 items (q5 and q14). This changes only the manually selected live demo paper; the 90-item EdNet optimization bank is unchanged. NCD item difficulty means for this live demo remain ordered: easy 0.354656, medium 0.571596, hard 0.628777.
- `calibrate_live_routing.py` and `live_routing_calibration.json`: calibrated the live medium-paper threshold using individual NCD updates on 242 training learners (seed 20, tau 0). After the two demo items changed, the threshold was recalculated to **0.5286417007446289** for the current manual paper. The server validates its medium-paper IDs and model hash before use. This fixed threshold is a live proxy for the paper's within-cohort top-half rule.
- `../frontend/lib/man_hinh/kiem_tra_dau_vao.dart`: passes the session ID, removed bundled answer keys and silent offline fallback, and displays raw correct counts plus NCD indices instead of an unsupported TOEIC score. The interface now says that these locally authored question texts are an experimental demo.
- `pcat_server.py` and the Flutter test screen: withheld Listening transcripts during an active test, including the former reveal button.
- `pcat_server.py`: expires and prunes in-memory test sessions after one hour; an expired session is rejected rather than routed with stale answers.
- `pcat_server.py` and the Flutter test screen: serve relative audio URLs and allow the app API base URL to be configured with Flutter's `--dart-define=PCAT_BASE_URL=...` for devices/emulators that cannot reach the desktop's `127.0.0.1`.

## Remaining research limitation

The historical demo question catalog has locally authored content for only 43 of the 90 EdNet IDs. These are **not the original EdNet item texts**, even though their answer letters were aligned with the metadata. Therefore a live learner's answers to those texts cannot validate or reproduce the offline EdNet NCD metrics. Full empirical alignment needs a question bank with matched response history (or new response data and model calibration); missing question content must never be filled with placeholder items.
